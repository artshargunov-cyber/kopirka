# Контекст проекта "Копирка" (Copier)

Этот файл предназначен для передачи контекста другой языковой модели (AI) или для продолжения работы с другого аккаунта. Если вы искусственный интеллект, прочитайте этот файл перед началом работы, чтобы понять архитектуру и текущий статус проекта.

## Основной Промпт для AI
**Роль:** Senior Python Developer & UI/UX Expert.
**Задача:** Продолжить разработку и поддержку приложения "Копирка" на базе PyQt6. Приложение предназначено для учителей: оно берет файл (картинку или PDF), обрезает его (при необходимости) и автоматически размножает на листе А4 так, чтобы поместилось максимальное количество копий. Для каждой копии автоматически подставляется "Имя ученика" и поле "Оценка" из заранее загруженного списка класса.

## Текущий стек технологий
- **Язык:** Python 3
- **GUI:** PyQt6 (Используется стиль Fusion, современный минималистичный дизайн)
- **PDF-движок:** PyMuPDF (`fitz`)
- **Работа с изображениями:** Pillow (`PIL`)

## Структура файлов
- `main.py`: Точка входа, инициализация `QApplication`, загрузка иконки приложения (`assets/icon.svg`).
- `ui.py`: Основной графический интерфейс (класс `MainWindow`). Содержит левую панель управления (кнопки, ползунок масштаба, управление списком учеников) и правую панель предпросмотра (QScrollArea).
- `crop_widget.py`: Кастомный виджет `InteractiveCropWidget` для интерактивной обрезки загружаемых картинок (с рамкой, 8 точками для изменения размера и возможностью перетаскивания).
- `pdf_processor.py`: Ядро обработки. Класс `PDFProcessor`. Вычисляет оптимальное размещение (колонки, ряды) в зависимости от масштаба, рисует линии реза, использует шрифт `Roboto-Regular.ttf` для корректного отображения кириллицы (в одну строку "Ученик: [Имя]    Оценка: ____"). Поддерживает автоматический поворот листа А4 (ландшафт/портрет) в зависимости от ориентации загруженной картинки.
- `roster_manager.py`: Логика сохранения и загрузки списка класса. Список кэшируется в локальный JSON файл (`roster_cache.json`).
- `assets/`: Папка с ресурсами (векторная иконка `icon.svg` и шрифт `Roboto-Regular.ttf`).

## Реализованные фичи (Версия 1.0)
1. Автоматический расчет сетки (Layout) на листе А4 для получения максимального количества копий.
2. Интерактивная обрезка исходной картинки с нативным интерфейсом на PyQt6.
3. Полная поддержка кириллицы в PDF с помощью встроенного TTF шрифта.
4. Авто-поворот финального PDF в альбомную или книжную ориентацию в зависимости от пропорций картинки.
5. Редактор списка класса во всплывающем окне (с сохранением состояния).
