# Контекст проекта "Копирка" (Copier)

Этот файл предназначен для передачи контекста другой языковой модели (AI) или для продолжения работы с другого аккаунта. Если вы искусственный интеллект, прочитайте этот файл перед началом работы, чтобы понять архитектуру и текущий статус проекта.

## Основной Промпт для AI
**Роль:** Senior Python Developer & UI/UX Expert.
**Задача:** Разработка и поддержка десктопного приложения "Копирка" на базе PyQt6. Приложение предназначено для учителей: оно берет файл (картинку, PDF или Word), обрезает его (при необходимости) и автоматически размножает на листе А4 так, чтобы поместилось максимальное количество копий. Для каждой копии автоматически подставляется "Имя ученика" и поле "Отметка" из заранее загруженного списка класса. Поддерживается работа с несколькими вариантами заданий.

## Текущий стек технологий
- **Язык:** Python 3.11+
- **GUI:** PyQt6 (стиль Fusion, современный минималистичный интерфейс)
- **PDF-движок:** PyMuPDF (`fitz`)
- **Работа с изображениями:** Pillow (`PIL`)
- **Сборка под Windows:** PyInstaller + Inno Setup (через GitHub Actions)

## Структура файлов
- `main.py`: Точка входа, инициализация `QApplication`, проверка фоновых обновлений с GitHub Releases.
- `ui.py`: Основной графический интерфейс (класс `MainWindow`). Содержит панель управления (кнопки, варианты заданий, список класса с ComboBox выбора варианта, настройки копий, печать и экспорт в PDF) и панель предпросмотра.
- `crop_widget.py`: Кастомный виджет `InteractiveCropWidget` / диалог `ImageCropDialog` для интерактивной обрезки картинок.
- `pdf_processor.py`: Ядро обработки (класс `PDFProcessor`). Поддерживает список вариантов (`variants`), оптимальное размещение карточек на листе А4, отрисовку линий реза, поддержку шрифта `Roboto-Regular.ttf` для кириллицы.
- `roster_manager.py`: Класс `RosterManager` для сохранения, загрузки и кэширования списка учеников и назначенных им вариантов (`roster_cache.json`).
- `updater.py`: Логика проверки обновлений через GitHub API.
- `utils.py`: Определение `VERSION = "1.6.0"`, получение путей к ресурсам (`get_resource_path`) и данным пользователя (`get_user_data_path`).
- `assets/`: Папка с ресурсами (`icon.ico`, `icon.svg`, шрифт `Roboto-Regular.ttf`).
- `.github/workflows/build-windows.yml`: CI/CD пайплайн сборки инсталлятора и портативной версии Windows на GitHub Actions.

## Реализованные фичи (Версия 1.6.0)
1. **Мульти-варианты заданий:** Кнопка «Добавить вариант», загрузка и отдельная обрезка файла под каждый вариант. В списке класса у каждого ученика появляется выбор варианта. При печати/генерации PDF каждый ученик получает карточку своего варианта с отметкой номера варианта в шапке.
2. Автоматический расчет сетки (Layout) на листе А4 для получения максимального количества копий.
3. Интерактивная обрезка исходной картинки с нативным интерфейсом на PyQt6.
4. Прямая печать на принтер (с автоматической настройкой ориентации листа) и экспорт в PDF.
5. Редактор списка класса во всплывающем окне с автосохранением в постоянную директорию пользователя.
6. Автоматическая сборка двух версий для Windows (установщик Inno Setup и Portable .exe) в GitHub Actions.
7. Решена проблема сборки PyInstaller с моделями PyMuPDF (`--collect-data pymupdf`).
