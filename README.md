# Копирка

Десктопное приложение для учителей начальных классов, предназначенное для автоматизации дублирования, персонализации и экономного размещения раздаточных материалов на листах А4.

## Установка и запуск (для разработки)

1. Убедитесь, что у вас установлен Python 3.8 или выше.
2. Клонируйте репозиторий или скачайте файлы.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python main.py
   ```

## Сборка в .exe (PyInstaller)

Чтобы собрать приложение в один исполняемый файл `.exe` для Windows (без консоли), выполните команду:

```bash
pyinstaller --noconfirm --onedir --windowed --name "Копирка" main.py
```
*Примечание: Если вам нужен ровно 1 файл .exe (немного дольше запускается), используйте флаг `--onefile` вместо `--onedir`.*

После успешной сборки ваш `.exe` файл будет находиться в папке `dist/Копирка/` (или просто `dist/Копирка.exe` если был использован `--onefile`).

## Работа с GitHub (Версионирование)

Чтобы инициализировать репозиторий и загрузить код на GitHub:
1. `git init` - инициализация репозитория.
2. `git add .` - добавление файлов (исключения из `.gitignore` будут пропущены).
3. `git commit -m "Initial commit"` - создание первого коммита.
4. Создайте пустой репозиторий на GitHub.
5. Свяжите локальный репозиторий с удаленным: `git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>`
6. Отправьте изменения: `git push -u origin master` (или `main`).

## Особенности
- **Smart Nesting**: Автоматический расчёт вместимости карточек на А4.
- **Персонализация**: Добавление имени ученика (в левом верхнем углу) и поля для оценки учителя.
- **Линии реза**: Добавление разделительных линий для удобного разрезания раздаток.
